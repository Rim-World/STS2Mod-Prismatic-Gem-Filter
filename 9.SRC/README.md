# Prismatic Gem Filter

Slay the Spire 2 模组。玩家持有遗物「棱彩宝石」时，按玩家勾选的开关，把跨角色发牌中「换你玩也几乎一定没用」的牌排除出候选。

本模组不按职业整池屏蔽。名单只收那些带其他职业专属机制、换了职业就废掉的牌。铁甲战士的牌多为力量与格挡这类通用机制，所以没有为他建立分组。判据见 `1.PRD/001-项目初期需求.md` 的 RQ-017。

许可：MIT

0.0.8 具备完整的开关体系：15 个分组开关，前六节按职业分节，第七节「其他」收纳不按职业归类的组，另有总开关，每个分组一个豁免子页。设置界面提供英语、简体中文、繁体中文三种文案，开关标题写明动作（例如「排除奥斯提牌」），说明附带本组卡牌张数。0.0.7 新增的「现版本有 bug 的牌」组默认勾选，用来挡掉当前版本里换职业拿到就失效的牌。0.0.8 新增「悲伤相关牌」组，默认勾选，成员是愚者围绕悲伤构筑的 12 张牌。

名单只收录能进入战斗奖励候选的卡牌：初始牌与先古牌已经剔除，多人限定卡只出现在「多人专属牌」一组。升级到 0.0.5 时存档里的设置会重置为默认值，见「设置」一节的说明。0.0.6 只改文案，不重置设置。

过滤范围与原版棱彩宝石的作用面严格相等：只有在棱彩宝石确实加宽本次发牌时才排除候选牌。万花筒、海玻璃、色彩哲学家、垃圾堆、普通商店、战斗内生成的飞溅与恋人都不受影响。设置页里可以把判定放宽为「只要出现其他职业的牌就生效」。

跨版本实测已完成：2026-11-17 在 0.111.1 与 0.113.1 上用同一份 DLL 验证过加载与对局内过滤，见 `3.DOCS/018-T-跨版本实测-111与113.md`。0.0.13 的运行时复测已在 0.111.1 与 0.113.1 上完成；0.113.1 的默认集合、分组关闭、总开关关闭与六个遗物入口见 `3.DOCS/022-T-0.113全量回归.md`。

## 构建

需要 .NET SDK 9 与本机游戏安装。

```
dotnet build PrismaticGemFilter.csproj -c Release
```

构建完成后自动把 `PrismaticGemFilter.dll` 与 `mod_manifest.json` 复制到游戏目录的 `mods/PrismaticGemFilter/`。

本机路径写在 csproj 里，换机器时覆盖即可：

| 属性 | 默认值 | 说明 |
|---|---|---|
| `Sts2Dir` | `C:\Game\Steam\steamapps\common\Slay the Spire 2` | 游戏安装目录 |
| `Sts2DataDir` | `$(Sts2Dir)\data_sts2_windows_x86_64` | 托管程序集所在目录 |
| `RitsuLibDeployRoot` | `C:\Game\Steam\steamapps\workshop\content\2868840\3747602295` | RitsuLib 创意工坊安装目录 |
| `RitsuLibCompatTarget` | `0.113.0` | RitsuLib 变体目录名 |
| `CopyModOnBuild` | `true` | 设为 `false` 时只产出，不部署 |

```
dotnet build PrismaticGemFilter.csproj -c Release "/p:Sts2Dir=D:\Steam\steamapps\common\Slay the Spire 2"
```

编译期绑定的是创意工坊里 RitsuLib 的 `compat/0.113.0/` 与 `shared/` 程序集，与游戏运行时实际加载的那一套一致。所有引用都是 `Private=false`，不复制进产物。

## 设置

游戏设置界面里有「棱彩宝石过滤」一页，分三部分。

**总开关**：一个过滤开关，以及一个两取值的下拉。

| 取值 | 含义 |
|---|---|
| 与棱彩宝石生效时机相同 | 默认。与原版棱彩宝石的作用面相等 |
| 当奖励中含有其他职业牌 | 任何来源的跨职业候选都会被排除 |

**分组开关**：共 15 项，前六节按职业分节，第七节「其他」收纳不按职业归类的组。首次启动排除 11 组：奥斯提攻击牌、召唤牌、灾厄牌、充能球牌、集中牌、奇巧牌、扎穿牌、铸造牌、辉星牌、现版本有 bug 的牌、悲伤相关牌。其余 4 组默认保留：箭矢牌、小刀牌、中毒牌、多人专属牌。

分组开关是整组操作：关掉保留全组，打开排除全组。说明行显示本组当前已排除张数，例如 `10/11`。分组开关与单卡豁免共用同一份状态，不存在「这组保留、那组排除」。

0.111 没有愚者角色。设置页在该版本上隐藏愚者分节与「箭矢牌」「扎穿牌」「悲伤相关牌」「现版本有 bug 的牌」四个空组，「多人专属牌」只显示 9 张；其余 11 个分组照常显示。判定按游戏程序集里有没有 `FoolCardPool` 类型，见 `4.ADR/013-设置项按游戏版本显隐.md`。

「现版本有 bug 的牌」组在 0.0.7 成立，成员是「遮天蔽日」。这张牌的效果从玩者职业卡池里筛射箭牌，别的职业拿到后效果异常。玩者自己是愚者时，这张牌在其职业卡池内，开关勾不勾都保留。

「悲伤相关牌」组在 0.0.8 成立，成员 12 张，都是愚者围绕悲伤构筑的牌。悲伤是愚者专属的衍生牌，别的职业拿不到生成源，这些牌换人玩几乎一定无效。组内默认豁免「活跃气氛」：它同时给悲伤与喜悦，不算纯负面。

**豁免清单**：每个分组后有一个入口，打开后可以逐张勾选该组要保留的牌。默认保留 10 张：精神过载与血肉戏法（灾厄）、洁净与唤起（召唤）、聚变与暴涨（球）、大爆炸（铸造与辉星共用一条）、汇流（辉星）、超能光束（集中）、活跃气氛（悲伤）。

豁免按卡牌记录，不按分组。同一张牌同时属于两个分组时，两个豁免页共享同一个开关。当前跨组卡只有「大爆炸」与「铸剑者」。分组开关关闭再打开会批量改写该组全部牌，原有的单卡调整会被清除。

改动即时生效，不需要重启。设置落盘在 `mod_data/PrismaticGemFilter/settings.json`，按 Steam 账号隔离。

存档里带一个架构版本号。版本号与模组当前版本不一致时，启动会把全部设置重置为默认值并写回存档。0.0.4 及更早的存档没有这个字段，因此升级后首次启动会重置一次，之后不再重置。0.0.13 的架构版本号是 5，落盘字段由 `Groups` 与 `Exemptions` 合并为 `Filtered`，升级后同样会重置一次。

界面文案随游戏语言变化：简体中文与繁体中文见汉语，其余语言见英语。卡名随游戏自身的语言显示。
