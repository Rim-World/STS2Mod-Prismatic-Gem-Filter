# Prismatic Gem Filter

Slay the Spire 2 模组。玩家持有遗物「棱彩宝石」时，按玩家勾选的开关，把跨角色发牌中「换你玩也几乎一定没用」的牌排除出候选。

本模组不按职业整池屏蔽。名单只收那些带其他职业专属机制、换了职业就废掉的牌。铁甲战士的牌多为力量与格挡这类通用机制，所以没有为他建立分组。判据见 `1.PRD/001-项目初期需求.md` 的 RQ-017。

## 构建

需要 .NET SDK 9 与本机游戏安装。

```
dotnet build PrismaticGemFilter.csproj -c Release
```

构建完成后自动把 `PrismaticGemFilter.dll` 与 `mod_manifest.json` 复制到游戏目录的 `mods/PrismaticGemFilter/`。

本机路径写在 csproj 里，换机器时覆盖即可：

| 属性 | 默认值 | 说明 |
|---|---|---|
| `Sts2Dir` | `C:\Game\Steam\steamapps\common\Slay the Spire 2` | 游戏安装目录 |
| `Sts2DataDir` | `$(Sts2Dir)\data_sts2_windows_x86_64` | 托管程序集所在目录 |
| `RitsuLibDeployRoot` | `C:\Game\Steam\steamapps\workshop\content\2868840\3747602295` | RitsuLib 创意工坊安装目录 |
| `RitsuLibCompatTarget` | `0.113.0` | RitsuLib 变体目录名 |
| `CopyModOnBuild` | `true` | 设为 `false` 时只产出，不部署 |

```
dotnet build PrismaticGemFilter.csproj -c Release "/p:Sts2Dir=D:\Steam\steamapps\common\Slay the Spire 2"
```

编译期绑定的是创意工坊里 RitsuLib 的 `compat/0.113.0/` 与 `shared/` 程序集，与游戏运行时实际加载的那一套一致。所有引用都是 `Private=false`，不复制进产物。

## 设置

游戏设置界面里有「棱彩宝石过滤」一页，分三部分。

**总开关**：一个过滤开关，以及一个两取值的下拉。

| 取值 | 含义 |
|---|---|
| 与棱彩宝石生效时机相同 | 默认。与原版棱彩宝石的作用面相等 |
| 当奖励中含有其他职业牌 | 任何来源的跨职业候选都会被排除 |

**分组开关**：共 16 项，前五节按职业分节，第六节「跨职业」，第七节「其他」收纳不按职业归类的组。首次启动排除 12 组：奥斯提攻击牌、召唤牌、灾厄牌、灵魂牌、充能球牌、集中牌、奇巧牌、扎穿牌、铸造牌、辉星牌、现版本有 bug 的牌、悲伤相关牌。其余 4 组默认保留：箭矢牌、小刀牌、中毒牌、多人专属牌。

分组开关是独立的总闸：关掉后本组不参与过滤，打开后本组未豁免的牌进入过滤池。分组开关不改写单卡豁免名单。说明行主行显示本组自身贡献，例如 `本组过滤 10/11`；组关闭时主行为 `本组过滤 0/11`。如果组内跨组牌仍被其他开启组过滤，说明行追加「本组仍有 x/y 在其他组被过滤」。

0.111 没有愚者角色。设置页在该版本上隐藏愚者分节与「箭矢牌」「扎穿牌」「悲伤相关牌」「现版本有 bug 的牌」四个空组；「其他」分节因唯一分组被隐藏而一并隐藏；「多人专属牌」只显示 11 张，其余 12 个分组照常显示。判定按游戏程序集里有没有 `FoolCardPool` 类型，见 `4.ADR/013-设置项按游戏版本显隐.md`。

「现版本有 bug 的牌」组在 0.0.7 成立，成员是「遮天蔽日」。这张牌的效果从玩者职业卡池里筛射箭牌，别的职业拿到后效果异常。玩者自己是愚者时，这张牌在其职业卡池内，开关勾不勾都保留。

「悲伤相关牌」组在 0.0.8 成立，成员 12 张，都是愚者围绕悲伤构筑的牌。悲伤是愚者专属的衍生牌，别的职业拿不到生成源，这些牌换人玩几乎一定无效。组内默认豁免「活跃气氛」：它同时给悲伤与喜悦，不算纯负面。

**豁免清单**：每个分组后有一个入口，打开后可以逐张勾选该组要保留的牌。默认保留 13 张：精神过载与血肉戏法（灾厄）、洁净与唤起（召唤）、聚变与暴涨（球）、大爆炸（铸造与辉星共用一条）、汇流（辉星）、超能光束（集中）、活跃气氛（悲伤）、守墓人、捕捉灵魂与降灵（灵魂）。0.111 上可见默认豁免为 12 张，因为「活跃气氛」所在的悲伤组隐藏。

豁免按卡牌记录，不按分组。同一张牌同时属于两个分组时，两个豁免页共享同一个开关。当前跨组卡有「大爆炸」「铸剑者」「挽歌」。单卡状态跨组唯一，但分组开关独立；同一张牌在一组关闭、另一组开启时，只要另一组包含它且它未豁免，仍会被过滤。

改动即时生效，不需要重启。设置落盘在 `mod_data/PrismaticGemFilter/settings.json`，按 Steam 账号隔离。

存档里带一个架构版本号。版本号与模组当前版本不一致时，启动会把全部设置重置为默认值并写回存档。0.0.4 及更早的存档没有这个字段，因此升级后首次启动会重置一次，之后不再重置。0.0.15 的架构版本号是 7，落盘字段恢复为 `Groups` 与 `Exemptions`，升级后同样会重置一次。

界面文案随游戏语言变化：简体中文与繁体中文见汉语，其余语言见英语。卡名随游戏自身的语言显示。
