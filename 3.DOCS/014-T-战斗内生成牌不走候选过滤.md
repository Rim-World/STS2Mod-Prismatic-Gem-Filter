# 014-T 战斗内生成牌不走候选过滤

- 记录时间：2026-11-16 20:54
- 对应版本：0.0.5（模组）、0.113.1（游戏）
- 起因：用户用 loadout 加了一张「遮天蔽日」，打出后没有生成任何箭矢牌，怀疑是本模组造成的

## 一、结论

这是游戏原本的行为，与本模组无关。

「遮天蔽日」从**玩家当前角色的卡池**里挑一张带 `Shoot` 标记的牌。用户的角色是静默猎手，静默猎手卡池里一张 `Shoot` 牌都没有，所以挑不到，什么都不加。

## 二、证据

### 2.1 这张牌怎么选牌

`MegaCrit.Sts2.Core.Models.Cards/BlotOutTheSky.cs:22-24`（0.113.1 反编译）：

```csharp
CardModel cardModel = CardFactory.GetDistinctForCombat(
    base.Owner,
    from c in base.Owner.Character.CardPool.GetUnlockedCards(...)
        where c.Tags.Contains(CardTag.Shoot)
        select c,
    1, base.Owner.RunState.Rng.CombatCardGeneration).FirstOrDefault();
```

关键点两条。

- `base.Owner.Character.CardPool` 是**玩家自己的职业卡池**，不是这张牌所属的愚者卡池。
- 过滤条件是 `CardTag.Shoot`（游戏内文案「发射」）。

### 2.2 静默猎手卡池里没有发射牌

0.113.1 里带 `CardTag.Shoot` 的牌共 17 张，逐张查卡池归属（`decompiled/*CardPool.cs` 的 `ModelDb.Card<类名>()` 列表）：

| 卡池 | 张数 | 卡牌 |
|---|---|---|
| `FoolCardPool` | 16 | ArrowStab、BlossomShot、BlotOutTheSky、DivineShot、Florescence、FoolishShot、HeavyShot、HobblingShot、LockedIn、MelodicShot、QuickShot、RainShot、RapidShot、RepeatShot、SkyShot、TrickShot |
| `TokenCardPool` | 1 | TheShot |

`SilentCardPool` 的 91 张牌里没有一张。所以静默猎手打出「遮天蔽日」时，候选集合为空，`FirstOrDefault()` 返回 `null`，效果落空。

### 2.3 这条链路不经过本模组的补丁点

本模组只在 `CardCreationOptions.GetPossibleCards(Player)` 上加后置补丁（`9.SRC/src/CardCreationPatch.cs:35`）。这条链路的三段都不经过它：

| 环节 | 位置 | 是否调用 `GetPossibleCards` |
|---|---|---|
| 卡牌效果调用 `CardFactory.GetDistinctForCombat` | `BlotOutTheSky.cs:22` | 否 |
| `GetDistinctForCombat` 内部只调 `FilterForRun` 与 `FilterForCombat` | `MegaCrit.Sts2.Core.Factories/CardFactory.cs:120-130` | 否 |
| `CardFactory` 里唯一的 `GetPossibleCards` 调用在 `CreateForReward` | `CardFactory.cs:218` | 只在战斗奖励链路 |

即使这条链路走进去，模式一的五道早退（`IsCardReward` 标记、卡池非空等）也会让补丁直接返回，见 `9.SRC/src/CardCreationPatch.cs:121-148`。

### 2.4 日志侧证

用户本轮测试的日志 `godot.log` 里有本模组的卡池自检：

```
[INFO] [PrismaticGemFilter] [self-check] pool=SilentCardPool declared=36 missing=0
```

自检只在过滤生效时打印，对象是 `player.Character.CardPool`，即玩家的职业卡池。本轮对局的角色是静默猎手。

## 三、复现与反证

| 做法 | 预期 |
|---|---|
| 用静默猎手打出「遮天蔽日」 | 不生成任何牌（当前现象） |
| 用愚者打出「遮天蔽日」 | 生成一张发射牌，卡牌显示本回合免费 |
| 静默猎手关闭本模组后打出 | 仍然不生成任何牌 |

第三条是判定本模组是否相关的关键：关掉模组现象不变，说明原因是游戏的选牌逻辑。

## 四、留给以后

- 本模组不需要为这张牌做任何改动。
- 若要过滤战斗内的生成牌，需要另找补丁点（`CardFactory.GetDistinctForCombat` 或 `CardFactory.GetForCombat`），那是新需求，不在现有 RQ 范围内。
- 跨职业拿牌本身是 loadout 类工具造出来的场景，正常对局不会出现「静默猎手持有愚者牌」。
