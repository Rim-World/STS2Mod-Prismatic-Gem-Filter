## 五、分组关闭

测试前把 `forge` 组从设置集合移出，得到 111 张排除牌。角色仍为缺陷机器人，使用同一场景脚本。

| 判据 | 数值 |
|---|---|
| 设置注册 | `groups=15 entries=180 filtered=111 stored=111 pages=16` |
| 索引 | `[index] version=5 groups=10 filtered=111` |
| 过滤行 | `candidates=513 removed=84 kept=429 poolGate=27 otherPool=427` |
| 对照 | 默认 `removed=94`，关闭 `forge` 后减少 10 张 |

`removed=84` 与 `94 − 10` 相等。`forge` 组有 11 张成员。`BIG_BANG` 默认豁免，不在初始集合内，所以关闭该组只减少 10 张已排除牌。跨组共享的 `THE_SMITH` 与 `BIG_BANG` 同时从 `star` 视图保留，符合「分组开关是批量命令」的语义。

同一设置在 0.113.1 上还能以铁甲战士场景复现：

| 判据 | 数值 |
|---|---|
| 设置注册 | `filtered=111 stored=111` |
| 索引 | `[index] groups=10 filtered=111` |
| 过滤行 | `candidates=513 removed=111 kept=402 poolGate=0 otherPool=428` |
| 发牌结果 | `HEADBUTT,FEAR,SWEEPING_BEAM` |

铁甲战士没有本职业卡在默认集合里，所以 `removed=111` 与集合大小相等。
