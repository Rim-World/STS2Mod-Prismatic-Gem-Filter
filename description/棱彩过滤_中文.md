# 如果你喜欢本mod，也欢迎看看我的其它mod。或许对你有帮助。

## ①设计目的

在beta113版本更新之后，新角色[愚者]又带来了大量难以被其他角色使用的卡牌，导致一些事件和遗物所提供的卡牌质量显著下降。

制作本mod的目标如下：

（1）基础功能（默认）：将部分对于其他职业完全无用的卡牌从“棱彩宝石”生效的相同口径中去除（举例说明：战斗奖励、星系仪等）；

（2）进阶功能（手动）：将部分对于其他职业完全无用的卡牌从所有发牌场景中去除（举例说明：飞溅、色彩哲学家、万花筒、海玻璃等）

本 mod 支持 default 0.111.1 与 public beta 0.113.1。

## ②主要功能

本 mod 在游戏内提供两种过滤模式，并在Ritsulib设置页提供精确到单卡的分类过滤与豁免调整功能。

（1）在默认工作模式下，当玩家使用的不是对应职业，且持有棱彩宝石时，在所有受到棱彩宝石影响的发牌口径，本mod将会过滤掉玩家所勾选的整组牌，并豁免掉其中被选定的牌。

举例：当玩家使用的不是亡灵契约师职业且持有棱彩宝石时，在战斗发牌、星系仪等受到棱彩宝石影响的发牌口径，将不会再遇到所有奥斯提攻击牌、奥斯提召唤牌、灾厄牌、灵魂牌（包括所有相关的攻击牌、技能牌和能力牌）。

但是有些牌是默认被豁免的，玩家仍然会在发牌时遇到它们。比如精神过载、洁净、血肉戏法、唤起、捕捉灵魂、守墓人、降灵等。

（2）在“所有出现其他角色牌的场景”的工作口径下，这种过滤会扩展到其余所有发放其他角色牌的场景。

比如：色彩哲学家、海玻璃（欧罗巴斯先古遗物）、万花筒（涅奥先古遗物）、飞溅等。

## ③其它功能与细节

你可以在Ritsulib设置页中对mod进行设置。若你在设置页调整名单，调整后的名单会即时生效。

本mod提供的过滤总共有十五组，默认只启用了八组。

部分多人卡牌被单独列出。

## ④ 影响

默认工作模式下，本mod将会显著提升棱彩宝石遗物的强度。

玩家拿到有用的其他职业牌的概率将会显著提高，带来更多样的玩法和更大的乐趣。

本 mod 不影响存档文件，也不存在任何遥测或联网行为。

## ⑤ 语言、环境与版本

本mod不影响任何游戏过程中的文本。在Ritsulib设置页，本mod仅支持英文和简体中文。

本 mod 依赖基础 mod：RitsuLib。

本 mod 支持 default 0.111.1 与 beta 0.113.1 。在 0.111.1 中，新角色「愚者」及其他beta113版本的内容将不会出现。

理论上只要没有大的 API 更新或游戏内容修改，本 mod 无须修改即可自动适配新版本。

## ⑥ 实现方式与兼容性

游戏在生成一组候选牌时，会先生成一个随机数序列，然后将本次的随机数对应为候选池中的牌。

本mod的生效方式是直接修改候选池。当玩家在Ritsulib设置页修改过滤名单时，会即时、全量地替换游戏的候选池。

本 mod 不保证与盗版、修改版、移动版、老旧版本或者冷门 mod、次级 mod 的兼容性。
