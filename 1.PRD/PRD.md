# 需求索引

## 项目

- 名称：Prismatic Gem Filter
- 本地目录：`STS2Mod-优化棱彩宝石`
- 载体：Slay the Spire 2 创意工坊模组
- 一句话目标：玩家持有遗物「棱彩宝石」时，按玩家自行勾选的开关，把跨角色发牌中「换你玩也几乎一定没用」的牌排除出候选。不按职业整池屏蔽，判据见 RQ-017。
- 当前阶段：需求梳理。细则尚未给出，本版仅记录已明确的部分。

## 非目标

- 不按职业整池屏蔽。只屏蔽「换你玩也几乎一定没用」的流派牌，见 RQ-017。铁甲战士的牌属通用机制，因此不建立分组。
- 不修改战斗内随机生成，例如「飞溅」与新生成的「添柴」。
- 不新增卡牌、遗物、角色。
- 不修改棱彩宝石的能量上限加成。
- 不替代社区已有的卡池排除类模组。

## 外部约束与依赖

- 游戏版本 0.113.1，提交 `d09d48e5`，构建日期 2026-11-14。主程序集为 `sts2.dll`。
- 0.113.0（提交 `16ac0fe3`）自 2026-11-15 起不再支持。游戏于 2026-11-14 更新到 0.113.1。
- 模组框架 RitsuLib 0.6.13（2026-11-14 发布），创意工坊条目 `3747602295`，用于设置页、持久化、本地化与补丁降级。它是硬依赖：玩家必须安装，本模组才加载。该形态由用户在 2026-11-15 16:56 确认。安装形态为单个 mod 目录，不含 `.pck`，自身无 mod 依赖。兼容包的构成、目录结构与运行时的版本选择规则见 [3.DOCS/007-T-RitsuLib兼容包与安装形态.md](../3.DOCS/007-T-RitsuLib兼容包与安装形态.md)。
- 不依赖 BaseLib。理由与证据见 [4.ADR/006-只依赖RitsuLib作为基础库.md](../4.ADR/006-只依赖RitsuLib作为基础库.md) 与 [3.DOCS/006-R-基础库选型调研.md](../3.DOCS/006-R-基础库选型调研.md)。
- 补丁框架 Harmony，游戏自带 `data_sts2_windows_x86_64\0Harmony.dll`。
- 目标版本 0.107.1 与 0.111.0 的程序集不在游戏目录。参考资料库 `C:\Users\13167\Desktop\Mod\STS2-Reference` 含 0.107.1、0.111.0、0.113.1 三个版本的完整反编译（`1.STS2-107Reference`、`2.STS2-111Reference`、`4.STS2-113.1Reference`）。`3.STS2-113Reference` 对应 0.113.0，已弃用。
