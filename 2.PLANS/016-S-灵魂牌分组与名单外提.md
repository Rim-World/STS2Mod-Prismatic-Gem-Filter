# 016-S 灵魂牌分组与名单外提

- 建立时间：2026-11-24 00:49
- 状态：部分完成
- 类型：S（小功能）
- 目标版本：0.0.15

## 背景

用户要求增加「灵魂牌」屏蔽名单。玩家不是亡灵契约师时，默认过滤灵魂牌；守墓人、捕捉灵魂、降灵默认豁免。灵魂牌中的多人限定卡按 ADR-009 只放入「多人专属牌」。

用户同时要求把名单从 `TMP/0.0.1/卡牌名单/` 迁到 `3.DOCS/`，并在每张牌的表格中增加「默认豁免」列。

## 范围

- 新增分组 `soul`，界面名「灵魂牌」，默认勾选，归入亡灵契约师分节。
- 非多人灵魂牌 9 张进入 `soul`；其中 3 张默认豁免。
- 多人限定灵魂牌 `GLIMPSE_BEYOND`、`SOULBOUND` 加入 `multiplayer`。
- `DIRGE` 同时属于 `summon` 与 `soul`，加入允许跨组集合。
- 名单 CSV 与 Markdown 从 `TMP/0.0.1/卡牌名单/` 移至 `3.DOCS/024-卡牌名单/` 与 `3.DOCS/024-T-卡牌过滤名单.md`。
- 新增文档生成脚本 `TOOLS/scripts/render-card-list-doc.py`。
- 设置架构版本由 6 升到 7。
- 项目版本由 0.0.14 升到 0.0.15。

## 非目标

- 不把灵魂牌按职业整池屏蔽。
- 不修改灵魂牌的战斗内生成链路。
- 不改变已有 10 张默认豁免。
- 不修改多人对局规则。

## 判定依据

扫描 0.113.1 反编译目录 `MegaCrit.Sts2.Core.Models.Cards/*.cs`，非 token 且源码引用 `Soul` 的卡牌共 11 张：

| 类名 | 中文名 | 多人限定 | 归属 |
|---|---|---|---|
| `CaptureSpirit` | 捕捉灵魂 | 否 | `soul`，默认豁免 |
| `DevourLife` | 吞噬生命 | 否 | `soul` |
| `Dirge` | 挽歌 | 否 | `soul` 与 `summon` |
| `GlimpseBeyond` | 彼岸一瞥 | 是 | `multiplayer` |
| `GraveWarden` | 守墓人 | 否 | `soul`，默认豁免 |
| `Haunt` | 纠缠 | 否 | `soul` |
| `Reave` | 剥夺 | 否 | `soul` |
| `Seance` | 降灵 | 否 | `soul`，默认豁免 |
| `Severance` | 切断 | 否 | `soul` |
| `Soulbound` | 灵魂绑定 | 是 | `multiplayer` |
| `SoulStorm` | 灵魂风暴 | 否 | `soul` |

`Soul` 本身是 `Token` 稀有度，不进入发牌候选，只列入 Token 附表。
