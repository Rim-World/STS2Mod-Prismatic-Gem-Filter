# 010-S 停止支持 0.107 版本

- 计划时间：2026-11-17 19:18
- 状态：已完成（2026-11-17 19:33；0.113.1 已验证，0.111.0 实测待用户执行）
- 依据：[ADR-011](../4.ADR/011-支持版本收窄为111与113.md)
- 版本：0.0.10

## 目标

受支持版本由三个收窄为两个：0.111.0 与 0.113.1。0.107.1 不再支持。

配套改动：`min_game_version` 改为 `0.111.0`；运行期判据删去 0.107.1 专用的「卡池非空」一条；文档同步。

## 步骤

- [x] 核对两个受支持版本的游戏侧差异：0.111 与 0.113.1 的 `PrismaticGem.cs`、`CardCreationOptions.cs` 逐字节相同。0.107.1 的 `CustomCardPool` 在 0.111 起不存在。
- [x] 改 `9.SRC/mod_manifest.json`：`version` 0.0.10，`min_game_version` 0.111.0。
- [x] 改 `9.SRC/PrismaticGemFilter.csproj` 注释与版本号。
- [x] 改 `9.SRC/src/CardCreationPatch.cs`：删去 `pools.Count == 0` 的早退，注释改为说明该条不可达。
- [x] 构建并部署。
- [x] 无头启动自检（0.113.1）。
- [x] 文档：ADR-011、ADR-002 与 ADR-008 的状态、SPEC 7.0、PRD、本计划、DOCS 008-E 补注、README、CHANGELOG、版本日志、TEST。

## 施工记录

- 判据删除依据：`GetPossibleCards` 是 `CardPools.SelectMany(...)`，卡池为空时返回空集合；后置补丁在候选计数处已经返回。该条在 0.111 与 0.113.1 上都不可达。
- 本机只有 0.113.1 的程序集。0.111.0 只做了反编译源码比对，运行期加载待用户降级实测。

## 未验证

- 0.111.0 的加载与发牌行为。用户将自行降级实测。
- 0.107.1 被 `min_game_version` 挡下的表现未实测。
